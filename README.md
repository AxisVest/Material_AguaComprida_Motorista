# AxisVest — Apostila Motorista

Versão responsiva pronta para GitHub Pages.

## Publicação
Em **Settings → Pages**:
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

## Responsividade
A página foi ajustada para:
- celulares;
- tablets;
- notebooks;
- desktops;
- impressão em A4/PDF.

O menu lateral vira menu móvel em telas menores.
